# Danh mục ảnh bằng chứng cần chụp thật

Chưa có ảnh nào được tạo hoặc giả lập. Chụp từ terminal/VS Code và trình duyệt GitHub sau khi thực hiện thật, rồi lưu các tệp sau vào thư mục này:

- A01: `01_vi_du_1.png` — VD01, input `[3,1,2]`
- A02: `02_vi_du_2.png` — VD02, input `[1,2,3,4]`
- A03: `03_tu_thiet_ke_1.png` — TK01, input `[9,1,8,2,7]`
- A04: `04_tu_thiet_ke_2.png` — TK02, input `[5,-1,5,0]`
- A05: `05_bien_1.png` — BIEN01, input `[4,3,2,1]`
- A06: `06_bien_2.png` — BIEN02, input `[2,2,2]`
- A07: `07_bien_3.png` — BIEN03, input `[]`
- A08: `08_input_khong_hop_le.png` — LOI01, độ dài 2001
- A09: `09_tong_ket_kiem_thu.png` — output toàn bộ bộ test (>=12 ca độc lập)
- A10: `10_clone_sach_chay_lai.png` — clone commit S vào thư mục mới, chạy demo và test
- A11: `11_github_repo_commit.png` — trình duyệt hiển thị repo và commit thật

Mỗi ảnh phải đọc được và gắn với commit đã chạy. Không dùng ảnh minh họa thay cho ảnh thực thi.
